### Requirements

This project has the following dependencies, as shown in `requirements.txt`:
- [pandas](https://pandas.pydata.org/)
- [numpy](https://numpy.org/)
- [matplotlib](https://matplotlib.org/)
- [semopy](https://semopy.com/)
- [networkx](https://networkx.org/)
- [bnlearn](https://pypi.org/project/bnlearn/)
- [pgmpy](https://pgmpy.org/index.html)

### Quick Start

To get started make sure the dependences are installed and run the `main.py` file.
